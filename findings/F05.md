# F05: Insecure Password Storage

| | |
| --- | --- |
| **Severity** | High |
| **OWASP** | A02:2021 – Cryptographic Failures |
| **CWE** | CWE-916 |

## Finding
Passwords were stored as unsalted MD5, which is fast to brute-force and identical for identical passwords, so a database leak exposed every account.

## Fix
Passwords are hashed with bcrypt (work factor 12) and a per-password salt; login verifies with a constant-time comparison and a dummy hash for unknown users to resist enumeration.

**Code:** `app/security.py` → `hash_password`, `verify_password`; `app/ledgerly.py` → `login`

## Retest
`tests/test_f05_crypto.py` — hashes aren't plaintext, the same password hashes differently each time, verify round-trips.

**Detection rule:** `weak-password-hash` in [`semgrep/rules.yaml`](../semgrep/rules.yaml) fails CI if this pattern reappears.
