# F02: Broken Access Control (IDOR)

| | |
| --- | --- |
| **Severity** | High |
| **OWASP** | A01:2021 – Broken Access Control |
| **CWE** | CWE-639 |

## Finding
`GET /invoices/<id>` returned any invoice by id. Alice could read Bob's invoice (and its confidential amount) by changing the number in the URL.

## Fix
Every access checks object ownership: the invoice's `owner_id` must equal the session user, unless that user's role is `admin`. Otherwise the server returns 403.

**Code:** `app/ledgerly.py` → `get_invoice`, `login_required`

## Retest
`tests/test_f02_access_control.py` — a user gets 403 on another's invoice, 200 on their own; admin sees any; anonymous gets 401.

**Detection:** covered by the access-control regression tests (object-level authorization is hard to detect statically; the tests are the guardrail).
