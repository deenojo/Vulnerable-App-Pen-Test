# F03: Stored Cross-Site Scripting

| | |
| --- | --- |
| **Severity** | High |
| **OWASP** | A03:2021 – Injection |
| **CWE** | CWE-79 |

## Finding
A user's `bio` was written into the profile HTML unescaped, so a bio of `<script>steal()</script>` executed in any viewer's browser.

## Fix
Output is HTML-escaped with `markupsafe.escape` (Jinja autoescaping stays on), and a `Content-Security-Policy: default-src 'self'` header blocks inline script as defence in depth.

**Code:** `app/ledgerly.py` → `profile`, `set_security_headers`

## Retest
`tests/test_f03_xss.py` — the script tag comes back as `&lt;script&gt;`, and the CSP header is present.

**Detection rule:** `jinja-unescaped-output` in [`semgrep/rules.yaml`](../semgrep/rules.yaml) fails CI if this pattern reappears.
