# F06: Security Misconfiguration

| | |
| --- | --- |
| **Severity** | Medium |
| **OWASP** | A05:2021 – Security Misconfiguration |
| **CWE** | CWE-16 |

## Finding
The app ran with `debug=True` (exposing the Werkzeug console), a hard-coded secret key, no security headers, and session cookies without secure flags.

## Fix
Debug is never set in the app factory; the secret comes from `FLASK_SECRET`; every response carries `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy` and CSP; session cookies are HttpOnly, Secure and SameSite=Lax; the `Server` header is removed.

**Code:** `app/ledgerly.py` → `create_app`, `set_security_headers`

## Retest
`tests/test_f06_misconfig.py` — headers present, Server header absent, cookie flags set.

**Detection rule:** `flask-debug-enabled` in [`semgrep/rules.yaml`](../semgrep/rules.yaml) fails CI if this pattern reappears.
